# E-COMMERCE

## Introduction

This is a project about operating systems and computer networks. The project is a E-Commerce system including a user interface (frontend), an admin interface, and a backend API.

## Folder Structure

- `frontend/`: React application for end users
- `admin/`: React application for administrators
- `backend/`: Node.js/Express API, database connection
- `db.sql`: Database schema file

## Technologies Used

- **Frontend/Admin:** React, Vite
- **Backend:** Node.js, Express, MySQL
- **Others:** Cloudinary, JWT, Email, RBAC

## Installation Guide

### 1. Backend

```powershell
cd backend
npm install
npm start
```

### 2. Frontend

```powershell
cd frontend
npm install
npm run dev
```

### 3. Admin

```powershell
cd admin
npm install
npm run dev
```
